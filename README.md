# Divex pour ordinateur

Installeurs de Divex, le carnet de plongée, pour Windows, macOS et Linux.
Téléchargez la dernière version sur la page **[Releases](https://github.com/JosephLALOT/divex-desktop-releases/releases/latest)**, puis connectez-vous avec votre compte Divex habituel.

| Système | Fichier à télécharger |
|---|---|
| Windows 10 et 11 | `Divex-Setup-<version>.exe` |
| macOS (Intel et Apple Silicon) | `divex-desktop-<version>.dmg` |
| Linux (la plupart des distributions) | `divex-desktop-<version>.AppImage` |
| Linux (Debian, Ubuntu) | `divex-desktop_<version>_amd64.deb` |

Les autres fichiers servent aux mises à jour automatiques : inutile de les télécharger. Une fois installé, Divex se met à jour tout seul.

**Windows.** Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur *Informations complémentaires*, puis *Exécuter quand même*.

**macOS.** Ouvrez le `.dmg` et glissez Divex dans *Applications*. Si macOS refuse d'ouvrir l'app au premier lancement, faites un clic droit sur Divex dans *Applications*, puis *Ouvrir*.

**Linux.** Rendez l'AppImage exécutable (`chmod +x divex-desktop-*.AppImage`) puis lancez-la, ou installez le `.deb` avec `sudo apt install ./divex-desktop_*_amd64.deb`.

Ce dépôt ne contient que les installeurs : le code de Divex n'est pas public. Les archives « Source code » que GitHub ajoute à chaque version ne contiennent que ce fichier et l'icône de l'app.

## Divex for desktop

Divex dive log installers for Windows, macOS and Linux. Download the latest version from **[Releases](https://github.com/JosephLALOT/divex-desktop-releases/releases/latest)** and sign in with your usual Divex account: `Divex-Setup-<version>.exe` on Windows, the `.dmg` on macOS, the `.AppImage` or `.deb` on Linux. The other files are used by automatic updates.
